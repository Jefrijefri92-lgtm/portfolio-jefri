
# Hari 3: JOIN - INNER JOIN & LEFT JOIN

**Tanggal:** 28 Mei 2026  
**Durasi:** 1 jam  
**Dataset:** Penjualan Kopi + Tabel Produk

## Yang Dipelajari
- `INNER JOIN` untuk gabungin data yang cocok di kedua tabel
- `LEFT JOIN` untuk ambil semua data tabel kiri
- Kombinasi JOIN + GROUP BY + agregasi
